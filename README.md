# 🤖 End-to-End Medical Chatbot using RAG Architecture (GenAI)

A Generative AI-powered medical chatbot built using **Retrieval-Augmented Generation (RAG)** architecture. This intelligent assistant answers domain-specific medical queries by retrieving and reasoning over context from medical PDF documents.

---

### 📅 Project Duration
**Jun 2025 – Jun 2025**

---

## 🔍 Description

This project is my first fully production-ready GenAI application. It integrates advanced natural language understanding with retrieval techniques to provide accurate and context-aware responses.

The chatbot:
- Parses medical PDFs
- Stores document embeddings
- Retrieves relevant chunks via semantic search
- Feeds context to an LLM to generate reliable responses

---

## 🔧 Key Contributions

- ✅ Integrated **LangChain** with **OpenAI API** for context-aware answer generation
- ✅ Used **Pinecone** to store and retrieve document embeddings with low-latency vector search
- ✅ Containerized the app with **Docker** for reliable and repeatable deployments
- ✅ Set up **CI/CD pipeline** with **GitHub Actions** for automated build and deployment
- ✅ Deployed to **AWS EC2**, using **AWS ECR** as the image repository and **IAM** for secure access control

---

## 🧰 Tech Stack

- 🧠 OpenAI (GPT-3.5)
- 🦜 LangChain
- 📦 Pinecone Vector Database
- 🐳 Docker
- 🔁 GitHub Actions
- ☁️ AWS (ECR, EC2, IAM)
